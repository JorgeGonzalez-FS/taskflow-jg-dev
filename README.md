# TaskFlow — JG Dev

Aplicación de gestión de tareas construida con HTML, CSS y JavaScript puro.

## Funciones
- Crear tareas con prioridad y fecha límite.
- Marcar tareas como completadas.
- Eliminar tareas.
- Filtrar por todas, pendientes y completadas.
- Buscar por título.
- Guardar datos en `localStorage`.
- Diseño adaptable a pantallas pequeñas.

## Ejecutar localmente
1. Descarga y descomprime la carpeta.
2. Abre la carpeta `taskflow` en Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes utilizar la extensión Live Server.
4. No necesita instalación de dependencias ni servidor.

## Limitaciones de esta versión
Los datos se guardan únicamente en el navegador actual. No hay cuentas de usuario ni sincronización entre dispositivos.

## Tecnologías
HTML5 · CSS3 · JavaScript · localStorage

Proyecto de demostración para el portafolio de JG Dev.
